# Anna's Bus Schedule

A convenient web application that allows users to view bus schedules and plan their trips efficiently. The application is built using Angular and deployed on GitHub Pages.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Building

To build the project run:

```bash
ng build
```


## Deployment

To deploy to project to GitHub Pages, run:

```bash
ng deploy
```

Once the deployment is complete, you can access the application at `https://bus.fscivan.com`.
